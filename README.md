# hfa-altermagnetism
PHYS 502 final project exploring altermagnetism with a Hartree-Fock Approximation

Based on the work by [Das et al.](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.132.263402#supplemental). Following their supplementary method and applied to the same two species cubic 2D lattice, we should replicate their results. 

All the code should be in the Jupyter notebook and already run. 

All code was written by hand without assistance from an LLM.
